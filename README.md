# سجل المدرس

## قاعدة البيانات المحلية

يستخدم التطبيق IndexedDB من خلال Dexie، لذلك تبقى البيانات على الجهاز ويعمل السجل دون إنترنت. مخطط البيانات موجود في `src/lib/database.ts` ويغطي:

- بيانات المدرسة والمرحلة والشعبة.
- الطلاب مع الترتيب الأبجدي والصور والملاحظات.
- حقول درجات الفصلين والمعدلات المحسوبة.
- الحضور والغياب وملفات الصور المرتبطة بتاريخ السجل.
- الاختبار اليومي ومحاولات الشفهي.
- أحداث الملاحظات: غياب، مشاغبة، وعدم تحضير.
- لقطات النسخ الاحتياطي وإعدادات النسخ السحابي.

تشغيل المشروع:

```bash
npm install
npm run dev
```
