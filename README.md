# سجل المدرس

واجهة أولية عربية متجاوبة لتطبيق سجل المدرس، مبنية بـ React وVite. تتضمن الصفحة الرئيسية، بيانات السجل، اختيار المرحلة والشعبة، البحث عن الطلاب، وتبويب إدارة الأسماء.

## التشغيل

```bash
npm install
npm run dev
```

الواجهة مصممة أولاً للهاتف، وتمهّد لإضافة قاعدة البيانات المحلية، الدرجات، الحضور، والطباعة في المراحل التالية.
